## 1. Sơ đồ tư duy dạng Mermaid (Trực quan hóa kiến thức)

```mermaid
mindmap
  root((BÀI 2: THỰC HÀNH SỬ DỤNG HỆ ĐIỀU HÀNH))

    Thực hành Hệ điều hành
      Quản lí tệp & thư mục
        File Explorer: Tạo mới, đổi tên, sao chép, di chuyển, xóa tệp
        Đường dẫn (Path): Tuyệt đối và tương đối
      Cấu hình hệ thống
        Control Panel / Windows Settings
        Cài đặt màn hình, độ phân giải, âm thanh, mạng kết nối
      Quản lí tiến trình & Ứng dụng
        Task Manager: Xem hiệu năng CPU, RAM, Disk
        Đóng ứng dụng bị treo (End Task)
      Bảo mật & Cập nhật
        Windows Security: Quét virus thời gian thực
        Windows Update: Cập nhật bản vá bảo mật
    
```

## 2. Flashcards - Thuật ngữ & Kiến thức cốt lõi

### 🏷️ File Explorer
> **Khái niệm cốt lõi:**  
> Công cụ quản lí hệ thống cây thư mục và tệp tin trên hệ điều hành Windows.

---
### 🏷️ Task Manager
> **Khái niệm cốt lõi:**  
> Tiện ích theo dõi mức chiếm dụng tài nguyên phần cứng và tắt các tiến trình bị treo.

---
### 🏷️ Control Panel / Settings
> **Khái niệm cốt lõi:**  
> Trung tâm thiết lập và tinh chỉnh mọi thông số cấu hình của máy tính.
