## 1. Sơ đồ tư duy dạng Mermaid (Trực quan hóa kiến thức)

```mermaid
mindmap
  root((BÀI 26: HÀM TRONG PYTHON))

    Khái niệm Hàm (Function)
      Khối lệnh được đặt tên, thực hiện một nhiệm vụ cụ thể và có thể tái sử dụng nhiều lần
      Giúp chương trình ngắn gọn, có cấu trúc, dễ sửa lỗi
    Định nghĩa hàm (def)
      Cú pháp:
        def <tên_hàm>(<danh_sách_tham_số>):
            <khối_lệnh>
            return <giá_trị_trả_về>
    Lời gọi hàm
      <tên_hàm>(<đối_số_truyền_vào>)
    Lệnh return
      Trả về kết quả tính toán cho nơi gọi hàm
      Kết thúc ngay lập tức việc thực thi hàm
      Nếu hàm không có return, giá trị trả về mặc định là None
    
```

## 2. Tóm tắt nhanh cốt lõi ghi nhớ (Flashcard dạng bảng)

| Khái niệm cốt lõi | Nội dung trọng tâm cần nhớ |
| :--- | :--- |
| **Từ khóa def** | Dùng để khai báo và định nghĩa một hàm mới. |
| **Lệnh return** | Trả về giá trị tính toán và lập tức thoát khỏi hàm. |
| **Lợi ích của hàm** | Tái sử dụng mã nguồn, chia nhỏ bài toán phức tạp thành các module dễ quản lí. |
