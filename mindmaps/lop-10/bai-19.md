## 1. Sơ đồ tư duy dạng Mermaid (Trực quan hóa kiến thức)

```mermaid
mindmap
  root((BÀI 19: CÂU LỆNH RẼ NHÁNH IF))

    Biểu thức điều kiện
      Các toán tử so sánh: ==, !=, >, <, >=, <=
      Toán tử lôgic kết hợp: and, or, not
    Cấu trúc rẽ nhánh dạng thiếu
      Cú pháp:
        if <điều_kiện>:
            <khối_lệnh>
      Quy tắc thụt lề (Indentation): Bắt buộc thụt lề 4 dấu cách
    Cấu trúc rẽ nhánh dạng đủ
      Cú pháp:
        if <điều_kiện>:
            <khối_lệnh_1>
        else:
            <khối_lệnh_2>
    Cấu trúc nhiều nhánh (elif)
      Dùng khi kiểm tra nhiều điều kiện kế tiếp nhau:
      if ... elif ... else
    
```

---

## 2. Tóm tắt nhanh cốt lõi ghi nhớ (Flashcard dạng bảng)

| Khái niệm cốt lõi | Nội dung trọng tâm cần nhớ |
| :--- | :--- |
| **Quy tắc thụt lề** | Khối lệnh sau dấu hai chấm (:) bắt buộc phải thụt đầu dòng đều nhau. |
| **Dạng đủ (if-else)** | Nếu điều kiện đúng thực hiện nhánh if, ngược lại thực hiện nhánh else. |
| **Đa nhánh (elif)** | Dùng elif để kiểm tra liên tiếp nhiều trường hợp phân loại. |
