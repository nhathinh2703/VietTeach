## 1. Sơ đồ tư duy dạng Mermaid (Trực quan hóa kiến thức)

```mermaid
mindmap
  root((BÀI 20: CÂU LỆNH LẶP FOR))

    Khái niệm vòng lặp xác định
      Vòng lặp biết trước số lần lặp
    Hàm range() trong Python
      range(n): Dãy số từ 0 đến n-1 (gồm n số)
      range(start, stop): Dãy số từ start đến stop-1
      range(start, stop, step): Dãy số nhảy cách step bước
      Ví dụ: range(1, 10, 2) sinh ra 1, 3, 5, 7, 9
    Cú pháp lệnh for
      for <biến_chạy> in <dãy_giá_trị>:
          <khối_lệnh_lặp>
    Các bài toán thường gặp
      Tính tổng dãy số S = 1 + 2 + ... + n
      Đếm các số thỏa mãn điều kiện
      In bảng cửu chương
    
```

## 2. Tóm tắt nhanh cốt lõi ghi nhớ (Flashcard dạng bảng)

| Khái niệm cốt lõi | Nội dung trọng tâm cần nhớ |
| :--- | :--- |
| **Hàm range(n)** | Sinh dãy số từ 0 đến n-1 (không bao gồm n). |
| **range(start, stop, step)** | Xác định mốc bắt đầu, mốc kết thúc và bước nhảy. |
| **Lệnh for** | Duyệt lần lượt từng phần tử trong một chuỗi/dãy số xác định. |
