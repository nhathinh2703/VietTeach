## 1. Sơ đồ tư duy dạng Mermaid (Trực quan hóa kiến thức)

```mermaid
mindmap
  root((BÀI 16: NGÔN NGỮ LẬP TRÌNH BẬC CAO VÀ PYTHON))

    Ngôn ngữ lập trình
      Ngôn ngữ máy (Machine code): Dãy nhị phân 0 và 1, máy tính hiểu trực tiếp
      Hợp ngữ (Assembly): Dùng từ viết tắt tiếng Anh, phụ thuộc phần cứng
      Ngôn ngữ bậc cao: Gần gũi ngôn ngữ tự nhiên, độc lập phần cứng (Python, C++, Java)
    Trình biên dịch & Trình thông dịch
      Biên dịch (Compiler): Dịch toàn bộ chương trình một lần thành mã máy (C/C++)
      Thông dịch (Interpreter): Dịch và thực thi từng dòng lệnh (Python)
    Giới thiệu Python
      Đặc điểm: Cú pháp ngắn gọn, dễ học, thư viện phong phú, đa nền tảng
      Môi trường làm việc:
        Chế độ tương tác (Shell / REPL >>>): Gõ lệnh và thấy kết quả ngay
        Chế độ soạn thảo (Script mode): Viết file .py và chạy toàn bộ
    
```
