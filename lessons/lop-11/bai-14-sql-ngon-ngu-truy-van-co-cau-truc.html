1. Mục tiêu bài học (Yêu cầu cần đạt)

Chuẩn Chương trình GDPT 2018 môn Tin học 11

Kiến thức

  • Nêu được khái niệm và vai trò tiêu chuẩn toàn cầu của ngôn ngữ SQL (Structured Query Language).
  • Nắm vững cú pháp của câu lệnh truy vấn dữ liệu cốt lõi: SELECT ... FROM ... WHERE ... ORDER BY.
  • Hiểu và viết được các câu lệnh cập nhật dữ liệu: INSERT INTO (thêm), UPDATE (sửa), DELETE (xóa).
  • Sử dụng thành thạo các toán tử so sánh (=, <>, >, <), toán tử logic (AND, OR, NOT) và toán tử tìm kiếm gần đúng (LIKE).

Kĩ năng

  • Viết được các câu truy vấn SQL để giải quyết các bài toán trích xuất dữ liệu quản lý học tập thực tế.
  • Phân tích và sửa được các lỗi cú pháp câu lệnh SQL phổ biến.

Phẩm chất & Năng lực

  • Hình thành tư duy lập trình truy vấn dữ liệu logic, chính xác và có tổ chức.

2. Khởi động

Tình huống khám phá gợi mở đầu bài (Theo SGV Tin học 11)

Đã xem

Tình huống mở đầu: Một thư viện điện tử có 500.000 đầu sách. Bạn đọc muốn tìm tất cả những cuốn sách thuộc thể loại "Tin học", xuất bản sau năm 2020 và sắp xếp theo giá tiền từ thấp đến cao. Làm thế nào máy tính có thể "hiểu" được yêu cầu này của con người?

🤔 Câu hỏi gợi mở suy nghĩ:

Ngôn ngữ tiêu chuẩn nào được các nhà phát triển sử dụng để ra lệnh trực tiếp cho Hệ quản trị CSDL trích xuất dữ liệu?

Gợi ý: Đó là ngôn ngữ SQL (Structured Query Language) với câu lệnh SELECT * FROM Sach WHERE TheLoai = 'Tin học' AND NamXB > 2020 ORDER BY GiaTien ASC;

3. Hình thành kiến thức

Khám phá nội dung bài học kết hợp tương tác thực hành

Đã xem
3.1

Khái niệm và vai trò của ngôn ngữ SQL

SQL (Structured Query Language - Ngôn ngữ truy vấn có cấu trúc) là ngôn ngữ tiêu chuẩn quốc tế (ANSI/ISO) dùng để tương tác, định nghĩa, điều khiển và thao tác dữ liệu trong tất cả các Hệ quản trị CSDL quan hệ hiện đại (MySQL, SQL Server, Oracle, PostgreSQL, SQLite).

SQL là ngôn ngữ phi thủ tục (Non-procedural / Declarative): Người dùng chỉ cần mô tả kết quả muốn nhận là gì (SELECT cột gì, WHERE điều kiện nào) chứ không cần phải viết thuật toán chỉ ra máy tính phải duyệt vòng lặp như thế nào.
3.2

Cú pháp câu lệnh truy vấn dữ liệu: SELECT

Cấu trúc câu lệnh truy vấn kinh điển nhất trong SQL:

SELECT Cot1, Cot2, ... -- Danh sách cột cần hiển thị (* nếu lấy tất cả)
FROM TenBang -- Bảng dữ liệu nguồn
WHERE DieuKien -- Lọc các hàng thỏa mãn điều kiện
ORDER BY CotSapXep ASC | DESC; -- Tăng dần (ASC) hoặc Giảm dần (DESC)
Toán tử so sánh & Logic trong WHERE:

So sánh bằng (=), khác (<> hoặc !=), lớn hơn (>), nhỏ hơn (<). Kết hợp điều kiện bằng AND, OR, NOT.

Tìm kiếm mẫu với LIKE & Kí tự đại diện:

Dấu % đại diện cho chuỗi kí tự bất kì. Ví dụ: HoTen LIKE 'Nguyễn%' tìm tất cả các bạn có họ Nguyễn.

3.3

Các câu lệnh cập nhật dữ liệu: INSERT, UPDATE, DELETE

Ba câu lệnh làm thay đổi nội dung dữ liệu trong bảng:

INSERT INTO HocSinh (MaHS, HoTen, DiemTin) VALUES ('HS01', 'Tran Van B', 9.5);

-> Thêm một bản ghi học sinh mới vào bảng HocSinh.

UPDATE HocSinh SET DiemTin = 10.0 WHERE MaHS = 'HS01';

-> Cập nhật điểm Tin học lên 10.0 cho học sinh có mã HS01.

DELETE FROM HocSinh WHERE MaHS = 'HS01';

-> Xóa học sinh có mã HS01 ra khỏi bảng (Lưu ý: Nếu không có WHERE sẽ xóa sạch toàn bộ bảng!).

Hoạt động tương tác: Điền từ vào chỗ trống

Gõ các từ khóa SQL vào ô trống rồi kiểm tra:

Để truy vấn trích xuất dữ liệu, ta dùng câu lệnh . Để lọc các học sinh có điểm lớn hơn 8, ta đặt điều kiện trong mệnh đề . Để sắp xếp thứ tự kết quả tăng dần hoặc giảm dần, ta dùng mệnh đề . Để sửa đổi dữ liệu đã có trong bảng, ta dùng câu lệnh . Để xóa bỏ bản ghi không còn dùng, ta dùng câu lệnh .
Từ khóa gợi ý: SELECT, WHERE, ORDER BY, UPDATE, DELETE

4. Luyện tập

Bài tập củng cố kiến thức theo SGK và định hướng SGV

Đã xem

Bài 1: Viết câu lệnh SQL trích xuất danh sách khen thưởng

Cho bảng HOC_SINH (MaHS, HoTen, Lop, DiemTB). Hãy viết câu lệnh SQL để hiển thị HoTen và DiemTB của tất cả các bạn học sinh thuộc lớp "11A1" có DiemTB từ 8.5 trở lên, sắp xếp điểm từ cao nhất xuống thấp nhất.

Câu lệnh SQL chuẩn xác:

SELECT HoTen, DiemTB
FROM HOC_SINH
WHERE Lop = '11A1' AND DiemTB >= 8.5
ORDER BY DiemTB DESC;

5. Vận dụng

Liên hệ ứng dụng thực tiễn trong cuộc sống

Đã xem

1. Cảnh báo nguy cơ khi chạy lệnh UPDATE và DELETE thiếu WHERE

Một nhân viên quản lý dữ liệu vô tình thực hiện câu lệnh: DELETE FROM KHACH_HANG; mà quên không gõ mệnh đề WHERE. Hậu quả gì sẽ xảy ra và làm thế nào để các hệ QTCSDL phòng tránh thảm họa này?

Hậu quả khôn lường & Biện pháp phòng tránh:

  • Hậu quả: Câu lệnh sẽ xóa sạch 100% dữ liệu của toàn bộ khách hàng trong bảng, gây sụp đổ hệ thống kinh doanh.
  • Chế độ Safe Updates: Các hệ QTCSDL (như MySQL Workbench) có cơ chế bật mặc định Safe Update Mode, sẽ tự động chặn và báo lỗi nếu người dùng chạy lệnh UPDATE hoặc DELETE mà không có mệnh đề WHERE chứa khóa chính.
  • Sử dụng Transaction (Giao dịch): Luôn bọc các lệnh thay đổi dữ liệu vào giao dịch START TRANSACTION; và chỉ COMMIT; khi đã kiểm tra kỹ lưỡng, nếu sai có thể ROLLBACK; để phục hồi tức thì.

6. Tóm tắt nội dung bài 14

Đã xem

1. Ngôn ngữ SQL

Chuẩn quốc tế để tương tác với mọi RDBMS. Bản chất là ngôn ngữ khai báo phi thủ tục.

2. Cú pháp SELECT

SELECT (chọn cột) -> FROM (chọn bảng) -> WHERE (lọc điều kiện) -> ORDER BY (sắp xếp ASC/DESC).

3. Bộ 3 câu lệnh cập nhật

INSERT INTO (thêm bản ghi), UPDATE (sửa dữ liệu), DELETE (xóa bản ghi - luôn nhớ kèm WHERE).

Câu 3: Câu lệnh SQL nào sau đây dùng để sửa lại số điện thoại cho học sinh có mã "HS05"?

Phần 2 Câu hỏi trắc nghiệm Đúng/Sai đa ý

Đúng 1 ý: 0.1đ • 2 ý: 0.25đ • 3 ý: 0.5đ • 4 ý: 1.0đ

Câu 1: Xét tính Đúng/Sai của các câu sau về ngôn ngữ SQL:

a) Từ khóa LIKE kết hợp dấu % giúp tìm kiếm các chuỗi văn bản gần đúng.
b) Câu lệnh DELETE FROM HocSinh; nếu không có WHERE sẽ báo lỗi và không xóa dòng nào.
c) Có thể kết hợp nhiều điều kiện lọc trong mệnh đề WHERE bằng từ khóa AND hoặc OR.
d) SQL phân biệt nghiêm ngặt giữa chữ hoa và chữ thường đối với các từ khóa lệnh SELECT, FROM.

Phần 3 Câu hỏi tự luận tổng hợp

Em hãy viết một kịch bản gồm 4 câu lệnh SQL hoàn chỉnh để thao tác với bảng SAN_PHAM (MaSP, TenSP, DonGia, SoLuongTon): (1) Thêm một sản phẩm mới, (2) Tìm các sản phẩm có đơn giá trên 500.000đ, (3) Giảm giá 10% cho sản phẩm có mã "SP01", (4) Xóa sản phẩm có số lượng tồn bằng 0.

Biểu điểm đánh giá chuẩn (Thang 10 điểm):

  • Câu lệnh 1: Thêm mới (2.5 điểm): INSERT INTO SAN_PHAM (MaSP, TenSP, DonGia, SoLuongTon) VALUES ('SP01', 'Chuột không dây', 600000, 50);
  • Câu lệnh 2: Truy vấn có điều kiện (2.5 điểm): SELECT * FROM SAN_PHAM WHERE DonGia > 500000;
  • Câu lệnh 3: Cập nhật giá trị (2.5 điểm): UPDATE SAN_PHAM SET DonGia = DonGia * 0.9 WHERE MaSP = 'SP01';
  • Câu lệnh 4: Xóa có điều kiện (2.5 điểm): DELETE FROM SAN_PHAM WHERE SoLuongTon = 0;
